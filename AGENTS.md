## Commands

- `npm run dev` — dev server. **Turbopack is the default bundler** (Next 16); CSS is routed through the `@tailwindcss/turbopack` loader rule in `next.config.ts`. Don't remove that rule or Tailwind stops processing.
- `npm run build`, `npm run start` — production build/run.
- `npm run lint` — ESLint 9 flat config (`eslint.config.mjs`), takes no args. Passes on the current tree.
- Typecheck: `npx tsc --noEmit` (there is no `typecheck` script). **Requires `.next/types` to exist** — it declares the global `LayoutProps` / `PageProps` types that every page/layout uses. On a fresh clone, run `npm run build` (or `npm run dev`) once first, or `tsc` fails with "cannot find name 'LayoutProps'".
- No test suite, no CI workflows exist. Don't invent test commands; `lint` + `tsc --noEmit` is the full verification loop.
- npm is the package manager (use `package-lock.json`; README's yarn/pnpm/bun suggestions are boilerplate).

## Architecture

- Next.js 16 App Router, React 19, TypeScript strict, path alias `@/*` → `src/*`.
- Tailwind CSS v4, **CSS-first config** (no `tailwind.config`): theme/tokens live in `src/app/globals.css`, which imports `tailwindcss`, `tw-animate-css`, and `shadcn/tailwind.css`.
- shadcn/ui is configured via `components.json` (style `base-nova`): primitives are **Base UI (`@base-ui/react`), not Radix**. Add components with `npx shadcn add <name>` → generated code lands in `src/components/ui/`.
- Class-name helper is the **`cn` package** (replaces clsx + tailwind-merge), re-exported from `src/lib/utils.ts`. Imports appear as both `import { cn } from "cn"` and `from "@/lib/utils"` — both are correct here.
- React Compiler is enabled (`reactCompiler: true` in `next.config.ts`).
- Routes: root layout `src/app/layout.tsx`; route groups `src/app/(root)/` (homepage) and `src/app/(auth)/` (signin, signup). Group folders don't affect URLs.
- Pages/layouts type their props with the generated globals `PageProps<"/route">` / `LayoutProps<"/route">` — they are ambient (no import), defined in `.next/types/routes.d.ts`, and **regenerated by `next dev`/`next build`**. After adding a route, run one of those before typechecking, or the new route won't be in the types.
